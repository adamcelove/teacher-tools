Where AI is kept out, on purpose

  • Grouping students. The Lab Group Mixer uses no AI and no network. Names are hashed to IDs; the only name file never leaves the machine.
  • Student data. A hook on the AI account blocks every path that holds student work or grades, so they never enter these tools.
  • Final judgment on anything a student reads. Every student-facing document passes a language auditor and a physics reviewer, then me, before it prints.
  • Derivation rules in answer keys. AI drafts; the rules for how a solution is written (symbolic before numbers, derive symmetry, never assert it) are mine and are checked.
